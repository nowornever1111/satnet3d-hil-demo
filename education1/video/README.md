# 案例二 · 演示视频素材

本目录存放"实验流程实录"视频的**采集脚本**与**合成脚本**。视频本身在
`../../video/案例二-实验流程.mp4`，并已插入 PPT 第 6 页。

## 为什么不是直接录屏

虚拟机里的图形界面窗口无法正常合成（Qt/OpenCV 窗口创建成功、坐标正确，但始终
不映射到屏幕；`x11grab` 与 GNOME 自带录屏都只抓到桌面壁纸）。所以改为：
**真实跑一遍流程 → 采集终端输出与接收端解码帧 → 合成 1080p 带字幕视频**。
数据、画面、时间戳都是本次实测的，没有编造。

## 两步复现

```bash
# 1. 真实采集（约 60 秒）：终端日志 + 接收端解码帧 + 时延 CSV + 桥接计数
bash capture_run.sh 45

# 2. 合成视频（约 3 分钟）
python3 make_video.py /tmp/cap /tmp/cap/案例二-实验流程.mp4
```

依赖：`ffmpeg`、`python3-opencv`、`python3-pil`、Noto CJK 字体。

## 若改用 EV 录屏 + 剪映重录

1. 在 VMware 里按上面 5 步顺序操作，**每步之间停 3–5 秒**，方便剪辑对齐。
2. EV 录屏设置：1080p、25 fps、仅录制 VMware 窗口。
3. 剪映中按上表加字幕，字号 28–32、底部居中、深色描边。
4. 建议每段保留 6–15 秒，总长控制在 2 分钟内，PPT 播放更顺。

注意：录屏前先 `bash capture_run.sh` 之外的步骤手工执行时，veth 网段地址必须
与仿真配置一致（192.168.100.0/24、192.168.101.0/24），否则桥接不起来。
